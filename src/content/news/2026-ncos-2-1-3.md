NCOS 2.1.3 is out. Grab the ISO from the [download page](/#download), or update an
existing install with `sudo pacman -Syu`.

## New first-party apps

- **Now Playing applet** — `ncos-now-playing-applet` puts the currently playing track
  in your panel, with album art and *Artist – Title*. It works with any MPRIS player
  (Spotify, browsers, media players).
- **Tiling Assistant** — `ncos-tiling-assistant` is a small GUI for managing COSMIC's
  auto-tiling exceptions: pick which apps should open floating instead of tiled.
  COSMIC Settings, Discord and Spotify now float by default.

Both are preinstalled on the new ISO and available from the [NCOS repo](/wiki/ncos-repo/).

## Assistant and snapshots

- **NCOS Assistant works out of the box** — `ollama` now ships on the ISO, so the
  [Assistant](/wiki/assistant/) no longer needs it installed separately.
- **grub-btrfs, tuned** — NCOS now ships a grub-btrfs config: snapshot entries in the
  boot menu are titled by date and description, and Docker/container subvolumes are
  skipped. See [Backups & Snapshots](/wiki/backups/).

## Desktop and installer

- **Accessibility zoom** is set up with mouse zoom shortcuts and 50% zoom steps.
- **Borderless panel** for a cleaner look.
- **Refreshed installer slideshow** — new artwork, updated text, and shortcut cards
  that match the current defaults (`Super+B` browser, `Super+;` settings).

## Cleanup

- `broadcom-wl` is no longer included on the ISO.
- Theming files now ship directly in `/usr`, so the separate `ncos-theming` package is
  no longer installed on new systems.
- Removed leftover configs for applets that NCOS doesn't ship.

> Already on NCOS? Update and add the new apps with:
>
> ```bash
> sudo pacman -Syu
> sudo pacman -S ncos-now-playing-applet ncos-tiling-assistant
> ```

Full changelog on the [release notes page](/wiki/release-notes/).
