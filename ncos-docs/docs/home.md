# Welcome to the NCOS Wiki

NCOS is a lightweight, rolling-release Linux distro built on **Arch Linux** with the
**COSMIC** desktop. It's ready out of the box: tiling, themes, snapshots, and an
offline AI assistant are already set up. This wiki covers installing NCOS and getting
the most out of it.

!!! tip "What's new in NCOS 2.1.3"
    A **Now Playing** panel applet, the **Tiling Assistant** for choosing which apps
    float, Ollama on the ISO so the Assistant works right away, and a tuned grub-btrfs
    setup. See the [release notes](release-notes.md).

## Get Help & Contribute
